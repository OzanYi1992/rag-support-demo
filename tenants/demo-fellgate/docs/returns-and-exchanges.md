# Returns and Exchanges

This page explains how long you have to send something back, what condition it
has to be in, and how an exchange differs from a return.

## Return window

The return window is **30 days** from the day the parcel is delivered, not from
the day the order is placed. Trail Club members at Ridge and Summit level have
**100 days** instead. The longer window is applied automatically when the order
was placed while signed in to a member account.

A return started on the last day of the window counts as in time. What matters
is the date the return is registered, not the date the parcel reaches us.

## Condition

Gear may be tried on and tested indoors. It may not have been used outdoors.

We accept a return when:

- all labels are still attached,
- the item is clean and dry,
- any waterproof membrane is unmarked,
- the item comes back with its stuff sack, poles, pegs or straps where these
  were part of the original delivery.

We do not accept a return when boots show sole wear, when a tent has been
pitched on ground, or when a garment has been washed. Field wear is not a
defect, and gear that has been used outdoors cannot go back into stock.

## What cannot be returned

- Gas cartridges, fuel and any other pressurised container.
- Avalanche transceivers once the sealed battery bay has been opened.
- Items cut to length, for example rope and webbing sold by the metre.
- Nutrition and water treatment tablets once the seal is broken.

These exclusions do not affect your rights where an item is faulty. A faulty
item is handled under the complaint route described in `gear-care-and-repairs`.

## How to register a return

Register the return in your account under Orders, or reply to the dispatch
confirmation. You receive a return label by email within one working day.

The label is valid for 14 days. A return sent on an expired label still reaches
us, but it travels unpaid and the postage is deducted from the refund.

Return postage is free for Zone A. For Zone B and Zone C the return label costs
a flat 9.90, deducted from the refund. Trail Club members at Summit level return
free from every zone.

## Exchanges

An exchange is a return plus a new order, handled as one case. It is the right
route when the item is correct but the size is not.

We hold the replacement size for **10 working days** from the day the exchange
is registered. If the return has not reached us by then, the hold lapses and the
replacement goes back into general stock.

An exchange may change size or colour within the same product. A different
product is a return plus a fresh order, because the price may differ.

Only one exchange per item. A second size change is a return.
