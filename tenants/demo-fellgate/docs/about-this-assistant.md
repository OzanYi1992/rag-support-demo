# About This Assistant

This assistant is an AI system: a language model writes the answers. It answers
only from the documents that Fellgate Outdoor has stored for it, not from
general knowledge.

It can help with orders and shipping, the countries we deliver to, sizes and
our range, returns and exchanges, payment and refunds, gear care and repairs,
and Trail Club membership.

If the documents do not cover a question, the assistant says so instead of
guessing and refers you to the Fellgate Outdoor support team.
